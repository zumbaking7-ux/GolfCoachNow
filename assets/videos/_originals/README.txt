Untouched masters. Never edit anything in this folder.

The instructional clips get images inserted and are likely to go through
several rounds of revision (pacing, slide placement, re-cuts). Every edit
starts from a copy of the file here, so a bad edit costs a re-run rather than
the original footage.

Put the originals here as they arrive from the client:

    _originals/swing.mp4
    _originals/putt.mp4
    _originals/short_game.mp4
    _originals/swing_correction.mp4
    _originals/putt_correction.mp4
    _originals/shortgame_correction.mp4
    _originals/intro.mp4

The folders alongside this one hold the processed versions the app actually
serves. Those are disposable and can always be rebuilt from here.
