# Project Brief: iOS Camera Module

## Client
John McGraw (Upwork)

## Budget
$300 fixed price (non-negotiable)

## Summary
Single-screen camera module in Swift using AVFoundation. The module records video, saves locally, uploads to our API endpoint, receives correction JSON, and displays a rep counter. This is a repeatable, standard workflow — no backend, no accounts, no dashboard.

## Required Skills
- Swift + AVFoundation
- iOS camera session configuration
- Video recording + file writing
- HTTP upload to API
- JSON parsing
- Basic UI layout

## Deliverables
1. Working iOS camera preview
2. Working video recording
3. Local file save
4. Upload to API endpoint
5. Receive correction JSON
6. Display rep counter
7. Clean, readable Swift code
8. Xcode project that builds without errors

## Mandatory Proof Before Payment
- Video demo of the module working on a physical iPhone
- Successful upload to our API endpoint
- Successful JSON response displayed in UI
- Final build approved by customer before release of payment

## Guarantee Requirement
Developer must have multiple past iOS camera builds and must guarantee successful delivery.
