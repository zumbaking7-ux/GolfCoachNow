Record your swing and get a correction back. This is a pre-release build for testing, not the Play Store version.

Download for Android

Android 8.0 or newer · about 22 MB

Installing it

  1. Tap Download for Android above.
  2. Your browser will warn that this kind of file can be harmful. That warning appears for every app not installed from the Play Store. Choose Download anyway.
  3. Open the downloaded file. Android will ask permission to install from this source — allow it, then press Install.
  4. Open the app and sign in with your email. A six digit code arrives in a few seconds.

If something goes wrong

  1. "App not installed" usually means an older copy is already on the phone. Uninstall it first, then install again.
  2. No sign in code? Check spam. If it is not there after a minute, tell us the address you used.
  3. iPhone? This build is Android only. The iPhone version is coming through TestFlight.

Prefer the web version? It runs in any browser with no install: open Golf Coach Now.
